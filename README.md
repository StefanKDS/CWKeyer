# CWKeyer

CWKeyer is a Morse code keyer project developed by **DL1SKD**. 
It's more a trainer than a real keyer, but the STM32 version has also a TX output.
I started these project for me to learn CW.


It includes two hardware implementations:

- **ESP8266** — the original version for ESP8266-based hardware.
- **STM32F746G-DISCO** — a version developed for the STM32F746G-DISCO board.

Select a platform below to view its project-specific README and documentation.

## ESP8266

For details about the ESP8266 implementation, see the [**CWKeyer ESP8266 project page**](https://github.com/StefanKDS/CWKeyer/tree/ESP8266/CWKeyer_ESP8266).

The [**CWKeyer User Manual**](https://github.com/StefanKDS/CWKeyer/blob/ESP8266/CWKeyer_ESP8266/Docs/CWKeyer_ESP8266_User_Manual.pdf) provides additional information about operating the ESP2866 version.

## STM32F746G-DISCO

For details about the STM32F746G-DISCO implementation, see the [**CWKeyer STM32F746G-DISCO project page**](https://github.com/StefanKDS/CWKeyer/tree/ESP8266/CWKeyer_F746/CWKeyer_F746).

The [**CWKeyer User Manual**](https://github.com/StefanKDS/CWKeyer/blob/ESP8266/CWKeyer_F746/CWKeyer_F746/docs/CWKeyer_User_Manual.pdf) provides additional information about operating the STM32 version.
